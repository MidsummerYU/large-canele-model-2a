# OST public dataset

`v1.1.jsonl` is copied unchanged from
https://huggingface.co/datasets/OSTswiss/MNLIoverSwissVotingBooklets (revision `9ff0859`, file `v1.1.jsonl`,
MIT License), published by OST for the Hack Apertus 2A challenge: 1,488 claims, each with its reference passage
from a Swiss federal voting booklet and an entailment label (0 entailment, 1 neutral, 2 contradiction).
